# CasaFlow

Gestão financeira familiar para Adriano e Adrielle. Fase 1 com dados mockados, sem banco e sem Supabase.

## Como rodar

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.

### Login demo

```txt
adriano@email.com
casaflow123
```

## Scripts

- `npm run dev` — Next.js + Turbopack
- `npm run test:run` — Vitest
- `npm run lint` — ESLint
- `npm run format` — Prettier
